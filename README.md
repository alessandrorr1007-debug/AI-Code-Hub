# AI Code Hub

Aplicación de escritorio para Windows orientada al desarrollo asistido por IA, con memoria por proyecto, referencias visuales y ejecución de tareas sin terminal visible.

## Estado

En construcción — Fase 1 (arquitectura Tauri 2 + React + TypeScript y 11 vistas). Las integraciones reales con Codex, Gemini, OpenCode, Android y GitHub se incorporarán por fases. No se solicitan ni almacenan claves de terceros.

El código se versiona aquí; los datos personales de proyectos deben permanecer locales y fuera de Git.
